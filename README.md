# Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Two-player Tic Tac Toe game
- Interactive game board
- Winner detection
- Reset game button
- Simple and user-friendly interface

## How to Play

1. Player X starts the game.
2. Players take turns clicking on the empty boxes.
3. The player who gets three same symbols in a row, column, or diagonal wins.
4. If all boxes are filled and no player wins, the game ends in a draw.
5. Click the Reset button to start a new game.

## Project Purpose

This project was created to practice JavaScript concepts such as DOM manipulation, events, functions, and game logic.
